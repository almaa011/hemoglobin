01 Key numbers

Spec grid

02 Signal chain

Panel + figure caption

The signal chain has four stages. Each introduces a constraint. Wrap a diagram panel in .figure to give it a numbered caption.[2]

.steps — numbered process list
  1. LED driver Drive current sets photon flux → DC photocurrent at the detector. Typical: 6–50 mA pulsed at 25–50% duty.[1]
  2. Photodiode + TIA Current-to-voltage conversion via feedback resistor: V_out = I_pd × R_f. Shot noise usually dominates.[2]
  3. ADC 18–22-bit conversion to resolve ~1% AC riding on the full-scale DC pedestal.
  4. DSP / MCU Band-pass filter, motion rejection, heart-rate extraction.

03 Callout types

Four semantic callouts

Use these consistently. Each color carries a meaning the reader learns to recognize after one page. Inline, translate jargon with a glossary term.

Formula / definition

Shot noise current: in = √(2 · q · IDC · BW) — where q = 1.6×10⁻¹⁹ C. At IDC = 10 µA and BW = 100 Hz, in ≈ 18 pArms.

Key finding

Shot noise from the DC photocurrent sets a hard floor that cannot be improved by better op-amp selection. The only lever is to reduce DC photocurrent while keeping AC signal.[2]

Warning

Ambient fluorescent lighting at 100–120 Hz aliases directly into the PPG band. Without synchronous detection, a window next to a fluorescent lamp saturates your TIA before you pick up a heartbeat.[3]

Conflict surfaced — green vs. red for motion noise

Researcher A states green has higher AC amplitude at rest. Researcher C notes green's higher melanin absorption makes it more motion-sensitive on darker skin than red/IR. Both are correct in different conditions.

07 New — code & tabs

Copyable code & tabbed views

Register writes and config the reader will paste go in a .code-block with a working copy button. Equivalent views (SPI vs I²C) go in .tabs.

AFE4490 · SPI register writes
// Enable SPI read, reset, then set LED currents
write(0x00, 0x000000);   // CONTROL0: SPI_READ=0
write(0x00, 0x000008);   // CONTROL0: SW reset
write(0x22, 0x003030);   // LED1/LED2 current (~30 mA)
write(0x1E, 0x000103);   // CONTROL2: TX enable, dynamic power down
MAX30102 · I²C register writes
// Mode config + SpO2 sample rate + LED pulse amplitude
i2c_write(0x09, 0x03);   // MODE_CONFIG: SpO2 mode
i2c_write(0x0A, 0x27);   // SPO2_CONFIG: 100 sps, 411us pulse
i2c_write(0x0C, 0x24);   // LED1_PA: red ~7 mA
i2c_write(0x0D, 0x24);   // LED2_PA: IR  ~7 mA
