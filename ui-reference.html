UI Reference style guide

This page renders the taste principles described in UI_REFERENCE.md. Every pattern below is the target for future page design — one confident accent, flat solid surfaces, geometric illustration, plain bold type, no glow / no glass / no gradient blobs.

01 Color

Palette

Two accents maximum. One dominant (fills, CTAs, numbered badges), one supporting (illustration linework only). Everything else is a neutral.

05 Hero

Headline + geometric illustration

Illustration sits beside the copy, built from primitives (squares, dots, thin connector lines) — never a stock photo or 3D render.

06 Feature grid

Thin line-art icons

Every card equal weight. Icons are single-stroke, monochrome or accent-stroked — never a filled gradient badge.

Overlap

Concentric / overlapping circle motif for "connected" concepts.

Toggle rows

Slider/toggle rows for settings or comparison lists.

Focus rings

Concentric rings converging on a solid accent dot.

Branch / tree

Distribution or hierarchy motif with dot endpoints.

07 Numbered list + orbit diagram

Particle / orbit illustration

Numbered badges are solid accent circles. Paired diagram is a dotted-orbit particle system, not a photo or icon set.
